Scorsync scores trampoline and tumbling meets. This site shows you how to run a meet with it, one step at a time.

## Pick your role

<CardGrid>
  <Card title="Host" href="/host/">
    You run the meet: rehearse, lock the schedule, go live, and handle changes on the day.
  </Card>
  <Card title="Offline host" href="/offline-host/">
    You run Scorsync Desktop on your own laptop at the venue.
  </Card>
  <Card title="Scoring table" href="/scoring-table/">
    You watch the floor, get judges signed in and keep sessions moving.
  </Card>
  <Card title="Judges and chairs" href="/judges/">
    You score routines on a tablet, or run a panel as the chair.
  </Card>
</CardGrid>

## Running a meet today?

Go straight to the meet-day runbook for [Scorsync Cloud](/runbook/scorsync-cloud/) or [Scorsync Desktop](/runbook/scorsync-desktop/). Not sure which one you have? See [Which setup do I have?](/start-here/which-setup/)

Something not working? Start with [Troubleshooting](/help/troubleshooting/).

**Who it's for:** Scoring table operator and host · Scorsync Cloud and Scorsync Desktop

**Not sure which way?** Hand each judge their printed sign-in sheet and use [Email and PIN](#email-and-pin). For a judge without a sheet, use [a desk code](#a-desk-code).

There are four ways in all, and they end in the same place. The screenshots come from Scorsync Desktop; Scorsync Cloud looks the same, with a different address.

| Way | Best when | What the judge needs |
| -- | -- | -- |
| [A desk code](#a-desk-code) | The judge is standing at the table | Any tablet with a browser |
| [Email and PIN](#email-and-pin) | The judge has their sign-in sheet | Any tablet with a browser |
| [A sign-in QR](#a-sign-in-qr) | The tablet has a camera | A camera |
| [The chair's panel sign-in](/judges/chair/sign-in-your-panel/) | The whole panel arrives at once | A camera, or a short code |

## Before you start

- You're signed in to Meet Control as the host or a scoring table operator.
- Judges are seated on the panel (Manage → **Judge Assignments**).
- Each judge's tablet is on the scoring Wi-Fi and can open the judges' address. See [Set up Scorsync Desktop and the venue network](/offline-host/set-up-the-venue-network/).

## A desk code

<Steps>

1. In Run, select **Judge assignments**, then **Sign in a judge**.

2. Type the judge's name, then select it in the list.

   ![The "Who's at the desk?" search, with Diane Holloway, Trampoline CH, found](./images/sign-in-a-judge-search.png)

3. Read the judge the address after **Go to** and the six-digit code. The code works once and lasts 10 minutes.

   ![The desk code window for Diane Holloway: go to scorsync.local\:8000/go and enter 202 001](./images/desk-code-window.png)

4. On the judge's tablet, open that address, type the code under **Sign-in code**, and select **Sign in**.

   ![The tablet's Sign in page with a Sign-in code box](./images/tablet-go-page.png)

5. Check that the tablet shows the judge's **Dashboard** with their name at the top right. Then select **Next judge** at the table, or **Done**.

   ![The chair's dashboard on a tablet: Diane Holloway, Chair, with an Open Flight button](./images/judge-dashboard-signed-in.png)

</Steps>

## Email and PIN

<Steps>

1. Find the judge's sign-in email and PIN. They're on the **Fallback** line of the desk code window (steps 1–3 above), and on Judge Assignments → **All credentials**.

2. On the judge's tablet, open the judges' address. The tablet shows **Log in to Scorsync**.

   ![Log in to Scorsync with Email address and Password or PIN boxes](./images/tablet-email-and-pin.png)

3. Type the email under **Email address** and the PIN under **Password or PIN**, then select **Log in**.

4. Check that the tablet shows the judge's **Dashboard**.

</Steps>

:::note
Judges added from a pasted list get a made-up email such as `official.9920001@judges.scorsync.invalid`. That's the email they type.
:::

:::caution
**All credentials** shows every judge's PIN at once. Keep that screen turned away from the room.
:::

## A sign-in QR

<Steps>

1. Go to Judge Assignments → **All credentials**.

2. On the judge's row, select **Sign-in QR**. It works once, and lasts 5 minutes.

   ![The "Sign-in QR for Wade Corrigan" window over the credentials list. The QR code and PINs are blurred in this picture](./images/sign-in-qr-window.png)

3. Ask the judge to scan the code with the camera of the tablet they'll judge on.

4. Check that the tablet opens the judge's **Dashboard**, then select **Done**.

</Steps>

## The chair's panel sign-in

The chair signs in first (any of the ways above), then signs in the rest of the panel from their own tablet. See [Sign in your panel](/judges/chair/sign-in-your-panel/).

## Get the panel scoring

There's no button to start a session. It starts when the chair opens the first athlete.

<Steps>

1. On the chair's tablet, select **Open Flight**.

2. Next to the first athlete in the run order, select **P1 Score**. Judges don't need to do anything: their tablets move to the scoring screen by themselves within about 10 seconds.

3. Check that the athlete shows under **On the floor**, and every judge shows "waiting" in the **Panel** list. Later, **Open pass 1** there takes the chair back to this athlete.

   ![The chair's flight view: Nora Hollister on the floor, an Open pass 1 button, and every judge "waiting" in the panel list](./images/chair-open-pass.png)

4. Each judge enters their marks.

   ![An execution judge's scoring screen: a mark for each skill, a number pad, and Submit Score](./images/judge-execution-pad.png)

5. Each judge selects **Submit Score**.

6. Check that the judge's tablet says "Score … sent to the chair. Waiting for the next athlete."

   ![The judge's tablet after submitting: Execution 8.7, "Score 8.7 sent to the chair"](./images/judge-score-sent.png)

7. When the marks are in, the chair selects **Confirm & next athlete**.

</Steps>

### At Level 8

At Level 8, the tablets tell judges what to score.

- The time of flight judge (TF on the chair's screen, ToF on the judge's tablet) sees "ToF doesn't count at Level 8. Skip this athlete." They don't need to do anything: ignore **Enter marks anyway**.
- In routine 1, the difficulty judge sees "First voluntary · DD not counted" and "Still enter the routine: repeats and requirements are checked." They enter the routine as usual.

![The Time of Flight judge's tablet: "ToF doesn't count at Level 8. Skip this athlete."](./images/judge-tof-skip-level-8.png)

When the chair selects **Confirm & next athlete**, **Incomplete Submissions** lists only judges whose score counts. The time of flight judge is never listed at Level 8. In routine 1, the difficulty judge is listed until they submit: wait for them rather than select **Advance Anyway**.

:::rule[What the rulebook says]
At Levels 8 and above, no difficulty is awarded for the first voluntary routine, but the difficulty judge's penalties still come off its total, such as 2.0 for each repeated element. Time of flight is added only at Level 10 (and Open, before it was retired).

**Source:** USA Gymnastics, *Development Program Code of Points: Trampoline* (2025–2029), Section 3, Rules 5.5 and 5.7, page 20; Section 4, Rules 9.1.1 and 9.1.2, page 27. Level 10 includes time of flight in 2026–27 (2026–27 Coaches T210, slides 41–43).
:::

:::review
The sentence on the difficulty judge's penalties in routine 1 is new (SCO-2191). Not yet signed off.
:::

## If something goes wrong

- **"That code didn't work. Ask for a new one."** The desk code was mistyped, already used or more than 10 minutes old. Select **New code** in the desk code window and try again.

  ![The tablet's Sign in page with "That code didn't work. Ask for a new one."](./images/tablet-go-code-refused.png)

- **"That email and password or PIN do not match."** Check the email and PIN on the Fallback line or in **All credentials**, and type them again. If it still fails, use a desk code instead.

  ![Log in to Scorsync with "That email and password or PIN do not match. Check them and try again."](./images/tablet-pin-refused.png)

- **"QR code already used."** Each sign-in QR works once. Select **Sign-in QR** again for a fresh one.

  ![Log in to Scorsync with "QR code already used. Ask for a fresh code, or sign in with your email and PIN."](./images/tablet-qr-already-used.png)

- **The QR code opens nothing, or "can't find the server"** (Scorsync Desktop). Check the tablet is on the scoring Wi-Fi. QR codes hold the laptop's number address (the one after **Or** in the Scorsync menu), so a code printed before the laptop's address changed no longer works. Show a fresh QR code, or sign in with a desk code.
- **A tablet can't open Scorsync** (Scorsync Cloud). Check the tablet has internet: it can open another website. Then sign the judge in with a desk code.
- **"Level 8 maximum DD is 6.0. 6.0 will be stored."** The difficulty judge typed a total above the level's maximum. Their tablet says so as they type, and the button reads **Use 6.0**. Check the total against the paper. If it's right, select **Use 6.0**. The chair sees the same warning when they type a DD on the difficulty card.

:::rule[What the rulebook says]
At Level 8, the second routine has a maximum routine difficulty of 6.0 (and a minimum of 4.0).

**Source:** USA Gymnastics, *Development Program Code of Points: Trampoline* (2025–2029), Section 3, Rule 6.2.4, page 20. Unchanged for 2026–27 (2026–27 Coaches T210, slide 62).
:::

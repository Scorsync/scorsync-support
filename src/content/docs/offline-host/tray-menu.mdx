**Who it's for:** Offline host · Scorsync Desktop

The tray menu is where you check that Scorsync is running and find the judges' address, even with the Scorsync window closed.

## Open the menu

- **Mac:** click the Scorsync icon in the menu bar at the top of the screen.
- **Windows:** right-click the Scorsync icon in the notification area, at the bottom right. If you can't see it, click the **^** arrow first. A left click opens the Scorsync window instead.

![The Scorsync menu: Running, the judges' address, a second address, Open Scorsync, Open in Browser, the backup items, Restart Server, Show Logs and Quit Scorsync](./images/tray-menu-running.png)

## What each item does

| Item | What it does | When to use it |
| -- | -- | -- |
| **● Running** (top line, grey) | Shows whether Scorsync is working. It's a status line, not a button, so it's always grey: a grey dot doesn't mean stopped. See the next table. | Every time you open the menu. |
| **Judges open: …** | The address judges type on their tablets. Click it to copy it. | Before judges sign in, and after any restart. |
| **Or: …** | A second address, made of numbers, for tablets that can't open the first one. | When a tablet says it can't find the server. |
| **Open Scorsync** | Opens the Scorsync window on the laptop. | After you've closed the window. |
| **Open in Browser** | Opens Scorsync in the laptop's usual web browser. | If you'd rather work in a browser tab. |
| **Last backup: …** (grey) | How long ago the last automatic backup ran. It should say 5 minutes or less. | A quick check during the meet. |
| **Back Up Now** | Makes a backup straight away. | At the end of each session. See [Back up your meet](/offline-host/backups/). |
| **Open Backups Folder** | Opens the folder of backups on the laptop. | If Scorsync support asks. See [Back up your meet](/offline-host/backups/). |
| **Restore from Backup…** | Replaces the meet with an older backup. | Only with Scorsync support helping you. |
| **Second Backup Folder…** | Copies every backup to a USB drive as well. | Before the meet. See [Back up your meet](/offline-host/backups/#copy-every-backup-to-a-usb-drive). |
| **Restart Server** | Stops Scorsync for about 5 seconds and starts it again. Tablets reconnect by themselves. | When the top line says "use Restart Server" or "Address changed", or after you set a second backup folder. Between athletes, never mid-routine. |
| **Keep New Address (judges moved to …)** | Only there after Scorsync started on a new address. Makes the new address the judges' address, and clears the warning. | After every judge has opened the new address. See [Keep the meet running](/offline-host/keep-the-meet-running/#if-something-goes-wrong). |
| **Show Logs** | Opens files for Scorsync support. | Only if support asks. |
| **Quit Scorsync** | Asks "Quit Scorsync?", then stops scoring for every judge if you select **Quit**. | Only after the meet. |

:::danger[Don't Quit Scorsync during the meet]
**Quit Scorsync** stops scoring for every judge. Scorsync asks "Quit Scorsync?" first: select **Cancel**. On a Mac, ⌘Q and Dock → Quit do the same. To get the window out of the way, close it instead. See [Keep the meet running](/offline-host/keep-the-meet-running/).
:::

## What the top line means

| It says | What to do |
| -- | -- |
| **◌ Starting…** or **◌ Preparing the database…** | Wait a few seconds. |
| **● Running** | Nothing. Scorsync is ready. |
| **▲ … stopped (…); restarting…** | Wait. Scorsync restarts that part by itself, usually within seconds. If it's still there after a minute, contact Scorsync support. |
| **▲ Address changed to … — judges are still on …** | Another program took the judges' address, so Scorsync started on a new one. See [Keep the meet running](/offline-host/keep-the-meet-running/#if-something-goes-wrong). |
| **▲ Network name is now … — use Restart Server** | Another computer on the network took Scorsync's name. Between athletes, select **Restart Server**, then give judges the new address after **Judges open**. |
| **✕** anything | Contact Scorsync support (support@scorsync.com). |

## If something goes wrong

- **There's no Scorsync icon.** Scorsync isn't open. Open it like any other app, and wait for **● Running**.
- **The top line says "Address changed to …"**, and the window shows a yellow banner. Select **Restart Server** between athletes, or move the judges and select **Keep New Address**. See [Keep the meet running](/offline-host/keep-the-meet-running/#if-something-goes-wrong).
- **"… is still running."**, for example "Back Up Now is still running." Back Up Now and Restart Server run one at a time. Wait a few seconds, then try again.

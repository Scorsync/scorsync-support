## Tips for good requests

- **Say what you want, not how.** "Place the unplaced entries" works better than a list of moves.
- **Name sessions and flights as the board does:** "Session 1", "flight B", "the tumbling of flight B".
- **Use @** to pick an athlete, session, flight or division.
- **Ask first, change second.** "Would it…?" and "What if…?" get an answer and change nothing.
- **One job per thread.** Select **+** to start a new thread for a new job.
- **Apply, then continue.** In a long job the agent stops after each card. Apply it, then select the button under the answer (for example **Continue the build**).

**Who it's for:** Host (meet director) · Scorsync Cloud and Scorsync Desktop

Once the schedule is locked, make changes from **Run** in Meet Control, not from Meet Builder. Find your change below.

## I need to...

| I need to... | Go to |
| -- | -- |
| Withdraw an athlete from an event or the whole meet | [Scratch an athlete](/host/meet-day-changes/scratch-an-athlete/) |
| Add an athlete who isn't on the start list | [Add a late entry](/host/meet-day-changes/add-a-late-entry/) |
| Move an athlete to another level or flight | [Change an athlete's level or flight](/host/meet-day-changes/change-level-or-flight/) |
| Answer the chair or a coach (the inbox in Run shows a number) | [Approve or reject requests](/host/meet-day-changes/approve-requests/) |
| Put a different judge in a seat | [Replace a judge mid-meet](/scoring-table/replace-a-judge/) |
| Stop the floor, for an injury or broken equipment | [Pause and resume a flight](/scoring-table/pause-and-resume/) |
| Get a quiet or stuck panel moving | [Free a stuck panel or nudge a station](/scoring-table/free-a-stuck-panel/) |
| Move an athlete who isn't ready, or mark them DNS | The chair does this: [Reorder, mark DNS or reinstate an athlete](/judges/chair/reorder-dns-reinstate/) |
| Fix a score after the flight is official | The chair does this: [Reopen an official flight to fix a score](/judges/chair/reopen-official-flight/) |

:::tip
In Run, press ⌘K (Ctrl+K on Windows) and type a name to find any athlete. The same box offers **Scratch an athlete…** and **Move athlete to another flight…**.
:::

## If something goes wrong

- **"The schedule is locked. Level, birth date, gender, flight and scratch go through Triage."** You tried the change in Meet Builder. Don't unlock: make it from Run, using the pages above.
- **A change you approved doesn't show on scorsync.com.** See [Watch publishing on the Sync Rail](/scoring-table/watch-publishing/).

**Who it's for:** Host (meet director) · Scorsync Cloud and Scorsync Desktop

Once the meet is running, make athlete changes from **Command Center** in Meet Control. Each change asks for a reason and goes in the log. Find your change below.

A locked schedule doesn't stop you. The lock protects sessions and flights. You can still change, move or scratch one athlete, in Command Center or in Meet Builder.

## I need to...

| I need to... | Go to |
| -- | -- |
| Withdraw an athlete from an event or the whole meet | [Scratch an athlete](/host/meet-day-changes/scratch-an-athlete/) |
| Add an athlete who isn't on the start list | [Add a late entry](/host/meet-day-changes/add-a-late-entry/) |
| Move an athlete to another level or flight | [Change an athlete's level or flight](/host/meet-day-changes/change-level-or-flight/) |
| Answer the chair or a coach (the inbox in Command Center shows a number) | [Approve or reject requests](/host/meet-day-changes/approve-requests/) |
| Put a different judge in a seat | [Replace a judge mid-meet](/scoring-table/replace-a-judge/) |
| Stop the floor, for an injury or broken equipment | [Pause and resume a flight](/scoring-table/pause-and-resume/) |
| Get a quiet or stuck panel moving | [Free a stuck panel or nudge a station](/scoring-table/free-a-stuck-panel/) |
| Move an athlete who isn't ready, or mark them DNS | The chair does this: [Reorder, mark DNS or reinstate an athlete](/judges/chair/reorder-dns-reinstate/) |
| Fix a score after the flight is official | The chair does this: [Reopen an official flight to fix a score](/judges/chair/reopen-official-flight/) |

:::tip
In Command Center, press ⌘K (Ctrl+K on Windows) to jump to **Search athletes or gyms**. Type a name and press Enter to open the athlete's page. Before you type, the same box offers **Scratch an athlete…** and **Move athlete to another flight…**.
:::

## If something goes wrong

- **You can't find Command Center.** Select **Command Center** in the **Manage | Command Center** switch at the top of Meet Control.
- **There's no Meet-day changes button on the athlete's page.** Only the meet host sees it. Sign in with your own host account.
- **A change you approved doesn't show on scorsync.com.** See [Check scores are reaching scorsync.com](/scoring-table/watch-publishing/).
